Web Application Security | Vulnerability Assessment & Remediation

Final Year BSc (Hons) Computer Science Project — 2025

Investigating Common Threats in Web Applications with Databases

Project Overview

I developed a functional PHP and MariaDB web application to investigate common cybersecurity vulnerabilities and demonstrate practical security mitigation techniques.

The project followed a structured security assessment lifecycle: identifying vulnerabilities, analysing their potential impact, implementing security controls and validating the results through further testing.

Technologies & Tools

* Security Testing: Burp Suite Professional, OWASP ZAP, Kali Linux
* Development: PHP, JavaScript, HTML, CSS, Bootstrap
* Database: MariaDB, HeidiSQL
* Infrastructure: Heroku, Apache, GitHub
* Security Frameworks: OWASP Top 10, CWE, CIA Triad

Key Security Findings

During testing, I investigated vulnerabilities including:

* Cross-Site Scripting (XSS)
* Cross-Site Request Forgery (CSRF)
* Improper input validation and output encoding
* Security misconfigurations
* SQL injection risks

Security Mitigations

Implemented multiple security controls, including:

* HTML Purifier and context-aware output encoding
* CSRF token generation and validation
* Parameterized database queries
* Secure authentication and session management
* HTTPS enforcement and HTTP security headers

Testing & Results

Using Burp Suite and OWASP ZAP, I conducted vulnerability assessments and targeted manual security testing.

Following remediation, I repeated security tests to verify the effectiveness of implemented controls.

Testing confirmed successful remediation of the demonstrated XSS and CSRF issues. Some Content Security Policy configuration challenges remained and were documented for future improvement.

Key Takeaways

This project strengthened my practical experience in vulnerability assessment, security testing, remediation and risk analysis.

Most importantly, it reinforced the importance of validating security controls rather than assuming an application is secure simply because protections have been implemented.
